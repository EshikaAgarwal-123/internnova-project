# internnova-project
Internnova Data Analytics Project
Retail Sales Analysis Project

Project Overview

This project focuses on analyzing retail sales data to understand sales performance, profitability, product categories, and regional trends.

The project uses Python, Pandas, NumPy, Matplotlib, and Power BI to clean, analyze, and visualize retail sales data.

Dataset

- Dataset: Sample Superstore
- Original Records: 9,994
- Records after cleaning: 9,977
- Columns: 13
- Missing values: 0 after cleaning

Tools and Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Power BI
- Git and GitHub

Project Workflow

1. Selected and loaded the retail sales dataset.
2. Cleaned the dataset and removed duplicate records.
3. Performed Exploratory Data Analysis (EDA).
4. Created visualizations using Python.
5. Built an interactive dashboard using Power BI.
6. Identified business insights and recommendations.

Visualizations

The project includes five Python visualizations:

1. Sales by Category
2. Profit by Category
3. Sales by Region
4. Quantity by Category
5. Profit vs Discount

Power BI Dashboard

The dashboard includes:

- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Category-wise Sales
- Region-wise Sales
- Profit by Category
- Sales by Sub-Category
- Region, Category, and Segment slicers

Key Business Insights

1. Technology generated the highest sales among all categories.
2. Technology also generated the highest profit.
3. Furniture had the lowest profit among the three categories.
4. The West region recorded the highest sales.
5. The South region recorded the lowest sales.

Recommendations

1. Review pricing, discounts, and costs in the Furniture category to improve profitability.
2. Use targeted marketing campaigns and promotional offers to improve sales in the South region.

Project Structure

- PowerBi: Power BI dashboard

- Reports: Project reports

Conclusion

This project helped analyze retail sales data and identify useful business insights. The analysis can help businesses improve sales performance and make better decisions.
